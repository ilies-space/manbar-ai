# منبر — Manbar

**خطبة الجمعة يفهمها الجميع.**

شاشة توضع في المسجد تعرض خطبة الإمام لحظة بلحظة بلغة ميسّرة للصم وضعاف
السمع: جمل قصيرة تتقدم مع كلام الإمام، الآيات بنص المصحف كما هي مع التفسير
الميسر، ومقاطع إشارة موثّقة للمصطلحات الشرعية.

مشاركتنا في تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي (المسار الثاني:
صناعة المحتوى متعدد اللغات والتوطين الثقافي).

## جرّب العرض

الموقع ثابت بلا أي اعتماديات أو خطوة بناء:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

أو ارفع المجلد كما هو على Netlify / Cloudflare Pages.

## ماذا يوجد في العرض

- **شاشة المسجد** — محاكاة كاملة لتجربة المصلي: نص ميسّر متزامن، بطاقة الآية
  بخط المصحف، إشارات المصطلحات، وضع الخطبة المرتجلة (بوسم «نص آلي غير
  مُراجَع» وتأخير بسيط)، وسيناريو ضجيج يتوقف فيه التيسير بشفافية.
- **لوحة الإمام** — رفع الخطبة، حالة التيسير والمراجعة الشرعية جملةً بجملة،
  الآيات المكتشفة والمصطلحات المرتبطة.
- **قاموس الإشارات** — المصطلحات الموثّقة من مترجمين معتمدين (الإشارات
  بشرية دائماً، لا يولّدها الذكاء الاصطناعي).
- **الأثر والقياس** — مؤشرات النجاح: الفهم، دقة التزامن، سلامة المعنى.

هذه نسخة MVP للعرض: التوقيتات والمقاطع والأرقام كلها محاكاة، ولا يوجد تعرّف
صوتي حقيقي بعد. الخطوة التالية ربط النموذج الصوتي والتجربة الميدانية في
مسجد تجريبي.

# منبر — Manbar

**خطبة الجمعة يفهمها الجميع.**

مترجم إشارة رقمي بالذكاء الاصطناعي يترجم خطبة الجمعة مباشرةً إلى لغة
الإشارة، ثم نصاً مكتوباً، ثم بلغة المصلي. يعمل على جوال المصلي وعلى شاشة
المسجد في ركن الصم دون حاجة لإمساك الجوال.

مشاركتنا في تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026 (المسار
الثاني — التوطين الثقافي: ننقل الخطبة إلى لغة الإشارة وإلى لغات المصلين).

## جرّب العرض

الموقع ثابت بلا أي اعتماديات أو خطوة بناء:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

أو ارفع المجلد كما هو على Netlify / Cloudflare Pages.

## ماذا يوجد في العرض

- **الخطبة المباشرة** — محاكاة كاملة لتجربة المصلي: المترجم الرقمي في
  مقدمة الشاشة يترجم كلام الإمام إشارةً، نص ميسّر متزامن تحته، الآيات
  بنص المصحف، تبديل إلى English (ترجمة فورية بترجمات آيات معتمدة)،
  وضع الخطبة المرتجلة بوسم «ترجمة آلية غير معتمدة»، وسيناريو ضجيج
  تتوقف فيه الترجمة بشفافية.
- **لوحة الإمام** — رفع الخطبة، الترجمة إلى الإشارة، توليد فيديو المترجم
  الرقمي، واعتماد المختص والمترجم جملةً بجملة.
- **مفردات الإشارة** — كل إشارة يؤديها المترجم الرقمي مصدرها تسجيل
  مترجم معتمد تُنقل حركته بالذكاء الاصطناعي — لا تُخترع إشارة أبداً.
- **الأثر والقياس** — مؤشرات النجاح: الفهم، دقة التزامن، دقة الإشارة.

هذه نسخة MVP للعرض: التوقيتات والأرقام محاكاة، ومقاطع الإشارة الحالية
بديل مؤقت لأداء المترجم الرقمي — لا يوجد تعرّف صوتي أو توليد حركة حقيقي
بعد. الخطوة التالية: ربط النموذج الصوتي، بناء نقل الحركة من تسجيلات
المترجم المعتمد، والتجربة الميدانية في مسجد حقيقي خلال أيام التحدي.

## البنية المستهدفة

تطبيق React Native · Expo لـ iOS و Android + شاشة المسجد ونسخة الويب،
وخادم ذكي: تحويل الكلام إلى نص (مقارنة Whisper / Chirp / ElevenLabs) ·
ترجمة فورية بترجمات آيات معتمدة (Claude / Gemini + Tanzil) · ترجمة إلى
قواعد لغة الإشارة · توليد فيديو المترجم الرقمي (Motion Transfer من
تسجيلات مترجم معتمد) · بث لحظي (Supabase Realtime).

# منبر — Manbar

خطبة الجمعة يفهمها الجميع.

منبر مشروع لتقديم خطبة الجمعة بلغة الإشارة، مع نص مكتوب وترجمة إلى لغة
المصلي. نضع المترجم الرقمي في مقدمة التجربة، على الجوال وشاشة المسجد.

مشاركة في تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026، المسار
الثاني: التوطين الثقافي.

## التشغيل

يمكن تشغيل الواجهة بأي خادم ملفات ثابتة، بلا حزم npm أو خطوة بناء:

```bash
python3 -m http.server 8080
```

- العرض الرئيسي: <http://localhost:8080/>
- المترجم التجريبي: <http://localhost:8080/live.html>
- محرر وضعيات الشخصية: <http://localhost:8080/tools/pose-editor.html>

يتصل المترجم أولاً بخدمة n8n المستضافة على خادم الفريق. تبقى مفاتيح OpenAI
على الخادم، ولا يحتاج المتصفح إلى مفتاح. يمكن نشر الملفات الثابتة على
استضافة تدعم HTTPS؛ يجب السماح بعنوانها في إعدادات CORS للخدمة.

مسارات الخدمة: `manbar-health` و`manbar-gloss` و`manbar-asr` تحت
`https://vmi3364148.contaboserver.net/webhook/`. ترسل الترجمة JSON يحوي
`text` وتستقبل `glosses`. يُرسل الصوت بصيغة WebM ويعود النص في `text`.

للتطوير أو كبديل محلي، تحتاج إلى Node.js 18 أو أحدث:

```bash
cp .env.example .env
node server.js
```

أضف مفتاح OpenAI إلى `.env` لتفعيل البديل المحلي. لا تشارك هذا الملف.
عند تعذّر n8n، يجرب العميل الخادم المحلي؛ وإذا لم تتوفر خدمة ذكاء اصطناعي،
يستخدم الترجمة بالقاموس والتعرّف الصوتي في المتصفح عندما يكون متاحاً.
الفشل أثناء معالجة الصوت يظهر كخطأ؛ لا يحدث تبديل تلقائي إلى Web Speech
في منتصف جلسة تسجيل قائمة.

يحتاج العرض إلى اتصال بالإنترنت لتحميل Three.js والخطوط. الميكروفون يحتاج
إذن المستخدم وHTTPS على الموقع المنشور. الخادم المحلي مخصص للتطوير.
قبل فتح API للجمهور، يلزم ضبط الوصول وحدود الطلبات وحفظ بيانات التنفيذ.

## ما يعمل حالياً

في `live.html` يمكن إدخال نص عربي أو استخدام الميكروفون. يرسل الخادم
الصوت إلى Whisper، ثم يطلب من GPT-4o-mini تسلسل معرّفات من قاموس يضم
18 حركة. يشغّل المتصفح هذه الحركات على شخصية ثلاثية الأبعاد باستخدام
Three.js، مع النص ومعرّفات الإشارات الظاهرة للمستخدم.

تُحسب وضعيات الذراعين بواسطة inverse kinematics، وتُضبط الأصابع من
قوالب الانحناء والتباعد. يتيح محرر الوضعيات تعديل الإطارات وتصديرها بصيغة
JSON. وضع الخطبة المجهزة يستخدم مطابقة أولية للكلمات؛ لا يشغّل بعد تسجيلاً
معتمداً مسبقاً.

أما العرض الرئيسي فيوضح تجربة المصلي ولوحة الإمام والمفردات والأثر.
توقيتاته وأرقامه وإجراءات الاعتماد فيه محاكاة، وليست نتائج دراسة ميدانية.

## حدود النسخة

الحركات الحالية تجريبية وغير معتمدة لغوياً. ليست منقولة بعد من تسجيلات
مترجم معتمد، ولا تكفي لإثبات صحة الترجمة إلى لغة الإشارة السعودية.
معالجة الكلمات غير الموجودة في القاموس والنفي وتسلسل طلبات الصوت تحتاج
إلى تحسين. لم تُثبت دقة الإشارة أو الفهم لدى مستخدمين صم في تجربة ميدانية.

في المنتج المقصود، تُراجع الخطبة المجهزة قبل عرضها. تبقى الترجمة المرتجلة
موسومة بأنها غير معتمدة، ويصاحب الإشارة نص مكتوب. الآيات تحفظ بنصها
المعتمد ولا تُعاد صياغتها؛ مطابقة الآيات في المسار الحي ما زالت قيد التطوير.

## تنظيم الكود

| المسار | المسؤولية |
| --- | --- |
| `server.js` | خدمة الملفات العامة ووساطة طلبات الصوت والترجمة |
| `js/live/asr.js` | تسجيل الصوت واختيار مدخل التعرّف الصوتي |
| `js/live/translate.js` | القاموس والترجمة والذاكرة المؤقتة |
| `js/live/live.js` | الواجهة ومطابقة النص وتنسيق التشغيل |
| `js/live/rig.js`, `player.js`, `scene.js` | الهيكل والحركة والعرض ثلاثي الأبعاد |
| `assets/lexicon/` | الإطارات الحركية وقوالب اليد |
| `js/data.js` | نصوص وبيانات العرض الرئيسي |

## التحقق

```bash
node --test tests/*.test.js
```

تتحقق الاختبارات من تحميل ملفات الواجهة ومنع الوصول إلى الملفات الخاصة.
لا تختبر صحة الترجمة الإشارية أو تجري طلبات إلى خدمات الذكاء الاصطناعي.

## الخطوة التالية

بناء حركات من تسجيلات بشرية مسموح باستخدامها، ومراجعتها مع مترجم معتمد.
ندرس استخدام بيانات [Isharah](https://snalyami.github.io/Isharah_CSLR/)
لتعلّم الربط بين النص والإشارات واستخراج الحركة. لم تُدمج بياناتها أو يُدرّب
نموذج عليها في هذه النسخة؛ يلزم الالتزام بشروطها وتأكيد الإذن المناسب.

React Native / Expo للجوال وSupabase للبث المتزامن جزء من خطة التطوير.
نقيس النجاح بالفهم، ودقة الإشارة بحكم مترجم معتمد، والتأخر بين الكلام
والإشارة. تطوير الفكرة والعرض بدأ قبل أيام التحدي، وتوضح سجلات Git مراحل
العمل؛ ينبغي فصل العمل السابق عن إضافات فترة المنافسة عند التقديم.

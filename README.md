# منبر — Manbar

**خطبة الجمعة يفهمها الجميع.**
مترجم إشارة رقمي بالذكاء الاصطناعي: يستمع إلى صوت الإمام، يحوّله نصاً،
يترجمه إلى تسلسل إشارات، ثم تؤديه شخصية ثلاثية الأبعاد على شاشة المسجد
وجوال المصلي — مع نص مكتوب مصاحب دائماً.

مشاركة في **تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026**
(المسار الثاني — التوطين الثقافي).

**جرّبه الآن:** <https://www.minbar-ai.com> — يفتح على شاشة المصلّي (الوضع العام)،
و**وضع الإمام** على <https://www.minbar-ai.com/?mode=imam> (المسجد ← الخطبة ← البث) دون أي تسجيل دخول.
رمز QR فيه يعمل من أي جوال متصل بالإنترنت.
النسخة المنشورة ثابتة: الذكاء الاصطناعي عبر طبقة n8n تلقائياً، ومزامنة
الجوال اللحظية (SSE) تتطلب الخادم المحلي أدناه.

## وضعان في التطبيق

| الوضع | لمن | المسار |
|---|---|---|
| **الوضع العام** (افتراضي) | المصلّي الأصم — يمسح رمز QR داخل المسجد | المترجم الرقمي في قسم، والخطبة مكتوبة في قسم منفصل تحته (لا تغطي اليدين). تظهر **الجملة التي قالها الإمام الآن فقط** والتي قبلها — لا تُكشف الخطبة مسبقاً. زر اللغة ظاهر دائماً. زر **«الاستماع المباشر»** يفتح ميكروفون الجوال فيستمع إلى صوت الإمام من مكبّر المسجد: تظهر الكلمات لحظة نطقها، وكل جملة تُطابَق مع الخطبة أو تُترجم فوراً بوسم «وضع مرتجل». وزر **«تجربة الاستماع»** يشغّل خطبة تجريبية مسموعة فتظهر الإشارة والنص معها. |
| **وضع الإمام** (خيار «انتقل لوضع الإمام») | الإمام / المسؤول في المسجد | اختر المسجد ← الخطبة (ملف أو **«صوّر خطبتك»**) ← **«مشاركة الخطبة»** ← شاشة البث بزر الميكروفون. ما يقوله يصل فوراً إلى أجهزة المصلّين على شبكة المسجد. |

**التبديل بين الخطبة المجهّزة والارتجال تلقائي:** كل ما يقوله الإمام يُطابَق مع الخطبة المشارَكة؛
ما يطابقها يُعرض بإشاراتها المجهّزة («خطبة مجهّزة»)، وما يرتجله يُترجم فوراً ويُوسم في الأسفل «وضع مرتجل».
لا يحتاج المستخدم أي ضغطة.

**وضع الإمام:** يُفتح مباشرة من `?mode=imam` دون اسم مستخدم أو كلمة مرور.

## الإشارات: 501 إشارة مسجّلة من مترجمين حقيقيين

- قاموس **KArSL** (جامعة الملك فهد للبترول والمعادن): 501 إشارة سجّلها مترجمون حقيقيون.
- استُخرجت حركة الذراعين واليدين والأصابع بـ MediaPipe Holistic، ثم حُوِّلت إلى **صيغة نقاط المسار
  الخاصة بمحرّك منبر** (`tools/karsl_to_waypoints.py` ← `assets/lexicon/signs_karsl.json`) — الشخصية
  والمحرّك كما هما؛ أُضيف للمحرّك فقط قبول اتجاه الكف وزوايا الأصابع المقيسة (متوافق مع الإشارات السابقة).
- قاموس الخطبة: نحو **1,565 صيغة** (مرادفات ومفاهيم الخطب) تربط الكلام بالإشارات
  (`assets/lexicon/aliases_karsl.json`)، مثل: «اتقوا الله» ← الله تعالى + خائف.

## «صوّر خطبتك»: من الورقة إلى منبر

خطبة الإمام غالباً مكتوبة على ورق. في خطوة «خطبة الجمعة» يضغط **«صوّر خطبتك»** فتُفتح الكاميرا
(صفحة أو عدة صفحات)، وتُرسل الصور إلى نموذج رؤية (**GPT-4o-mini**) يفرّغ الكتابة العربية حرفياً دون
إضافة أو حذف أو تصحيح. يظهر النص في مربع قابل للتعديل، ولا يُعتمد إلا بعد مراجعة الإمام، ثم يُقسَّم
جملاً وتُجهَّز إشاراتها كأي ملف خطبة.

- الكود: `js/live/scan.js` (الواجهة)، `/api/ocr` في `server.js` (الخادم المحلي)، و`api/ocr.js` (دالة Vercel).
- المفتاح على الخادم فقط: `OPENAI_API_KEY` في `.env` محلياً، أو في Environment Variables على Vercel.
- الصور تُصغَّر قبل الإرسال (1600px) ولا تُخزَّن.

## الآيات: من مصحف مجمع الملك فهد فقط

عند ورود آية في الخطبة يتعرّف عليها التطبيق ويعرض **نصها الرسمي من مصحف مجمع الملك فهد**
(الرسم العثماني، رواية حفص) مع اسم السورة ورقم الآية، وترجمة معانيها **من ترجمات معتمدة**
(وليس ترجمة آلية). لا يولّد أي نموذج نص آية. التفاصيل ومنهجية التحقق: **[SOURCES.md](SOURCES.md)**.

## الخطبة الصوتية للعرض التجريبي

```bash
node tools/make_demo_audio.cjs     # يولّد assets/audio/khutbah_01..11.mp3 بصوت OpenAI من مفتاح .env
```
النص مشكول بالكامل والآيات بتشكيل المصحف لضمان النطق الصحيح. **استمع لكل ملف قبل التسليم.**

النسخة المنشورة تستخدم ملفات مولّدة بصوت ElevenLabs «Rawi» (الفصحى) لنفس النص المشكول؛ ضعها في `assets/audio/` عند التشغيل المحلي.

## كيف يعمل

```
صوت الإمام ← مايكروفون المتصفح
   │  تقطيع عند السكتات (VAD تكيّفي يتعلم ضجيج القاعة + مرشّح هلوسات Whisper)
   ▼
تفريغ صوتي (Whisper) ──► ترجمة إلى Gloss (GPT-4o-mini مقيّد بمعجم 18 إشارة)
   ▼                                    │
محرّك الإشارة (Three.js) ◄──────────────┘
   • نقاط مسار لليدين + حلّ Inverse Kinematics ثنائي العظام
   • محاور انحناء الأصابع مُعايَرة من الهيكل نفسه، لكل يد على حدة
   • تهجئة بالأصابع للكلمات خارج المعجم
   ▼
شاشة المسجد ──(SSE)──► جوالات المصلين المتزامنة + نص مكتوب مصاحب
```

**ثلاث طبقات للذكاء الاصطناعي** — يختار العميل أول طبقة متاحة تلقائياً:

| الطبقة | مكان المفتاح | ملاحظات |
|---|---|---|
| خدمة n8n المستضافة | على الخادم — لا مفتاح في المتصفح | الافتراضي؛ مسارات `manbar-health/gloss/asr/translate/ocr` تحت `https://vmi3364148.contaboserver.net/webhook/` |
| خادم محلي `server.js` | `.env` | احتياط + مزامنة SSE + بث QR على الشبكة المحلية + `/api/ocr` لـ«صوّر خطبتك» |
| وضع مباشر (متصفح ← OpenAI) | قائمة الإعدادات ⚙ | تجريبي؛ المفتاح في localStorage فقط |

بدون أي مفتاح: ترجمة بالقاموس المحلي، وWeb Speech للتعرف الصوتي حيث يتاح.
الفشل أثناء جلسة تسجيل قائمة يظهر كخطأ ولا يبدَّل المصدر في منتصفها.

## التشغيل خطوة بخطوة

**المتطلبات:** متصفح Chrome/Edge حديث، واتصال إنترنت (Three.js والخطوط من CDN).
للخادم المحلي: Node.js 18+.

```bash
git clone https://github.com/ilies-space/manbar-ai.git
cd manbar-ai

cp .env.example .env     # ضع OPENAI_API_KEY=... (اختياري) — لا تشارك الملف
node server.js           # ⇒ http://localhost:8080
```

1. **شاشة المسجد:** افتح `http://localhost:8080` وأكمل الإعداد:
   المسجد ← الخطبة (جرّب إسقاط ملف ‎.txt حقيقي) ← **ابدأ البث**.
2. **الجوال:** امسح رمز QR. محلياً يلزم نفس شبكة الواي فاي (اسمح لـ node في
   جدار الحماية إذا سأل) وسترى «متزامن مع شاشة المسجد»؛ على النسخة
   المنشورة يعمل من أي شبكة لكن ببث مستقل موسوم.
3. **الميكروفون:** الزر الدائري أسفل المنتصف. تكلّم بجمل قصيرة مع وقفة
   بينها؛ «تتبع الخطبة» يطابق كلامك مع الجمل المجهّزة، و«مرتجل» يترجم
   مباشرة بوسم واضح. (الميكروفون يتطلب إذن المستخدم، وHTTPS عند النشر.)
4. **الإعدادات ⚙:** رابط n8n خاص بكم أو مفتاح OpenAI للوضع المباشر.
5. **بدائل التشغيل:** واجهة فقط بلا Node؟ أي خادم ملفات ثابتة يكفي
   (`python3 -m http.server 8080`) وستعمل طبقة n8n — بلا مزامنة جوال محلية.
   محرر الإشارات: `tools/pose-editor.html`.

**الاختبارات:**

```bash
node --test tests/*.test.js
```

تتحقق من طبقات الاتصال، وبوابة الصوت، وخدمة الملفات ومنع الوصول للملفات
الخاصة — ولا تختبر صحة الترجمة الإشارية لغوياً.

الدليل الموسّع للتحكيم (استيراد سير n8n، الأمان، استكشاف الأعطال):
**[SETUP.md](SETUP.md)**

## حدود النسخة — بصراحة

- الإشارات الـ501 **منقولة من تسجيلات مترجمين (KArSL)**، لكن تحويلها إلى نقاط مسار تقريبي
  (بعض الإشارات القريبة من الوجه أخفض قليلاً من الأصل)، **وربط مفردات الخطبة بها تقريبي ويحتاج
  مراجعة مترجم معتمد**. لا توجد تعابير وجه بعد. الشاشة موسومة بذلك.
- خطوة «الاعتماد» في الإعداد محاكاة مكتوبة صراحةً. أشكال حروف التهجئة
  مميّزة لكنها مبدئية حتى اعتماد المترجم.
- لم تُقَس دقة الإشارة أو الفهم مع مستخدمين صم ميدانياً بعد. مطابقة الآيات
  في المسار الحي قيد التطوير، والآيات لا تُعاد صياغتها أبداً.
- **الخطوة التالية:** حركات من تسجيلات بشرية مُصرَّح بها يراجعها مترجم
  معتمد، وندرس بيانات [Isharah](https://snalyami.github.io/Isharah_CSLR/)
  (لغة الإشارة السعودية) للربط النصي-الإشاري والتحقق الآلي — لم تُدمج ولم
  يُدرَّب عليها نموذج في هذه النسخة، ويلزم تأكيد إذن استخدامها.
- تطوير الفكرة بدأ قبل أيام التحدي وسجلات Git توثّق المراحل؛ يُفصل العمل
  السابق عن إضافات فترة المنافسة عند التقديم.
